# Ultra AIM Studio Roadmap

### Phase 1 — Rebrand Lite into Ultra AIM Studio
Focus on brand identity, color palette, typography, metadata, logos, header/footer, and basic layout structure.

### Phase 2 — Public Design Upgrade
Enhance homepage animations, Works page layouts, responsive scaling, and overall visual polish for end-users.

### Phase 3 — Admin Design Upgrade
Refine the Admin Dashboard UI and establish the foundational Media Manager.

### Phase 4 — Player Features
Reintegrate any missing video player enhancements (e.g., subtitles toggle, precise player timings).

### Phase 5 — Users / Subscribers / Notify Me
Polish authentication flows, granular user notification preferences, and complete CTA loops for unreleased content.

### Phase 6 — Subtitle System
Rebuild a lightweight, modern subtitle system natively in the new Ultra architecture.

### Phase 7 — Data Migration
Execute a clean mapping and migration of production data from the Old AIM `Project` schema to the Ultra `Work` schema.
